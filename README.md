## 📌 About the Project

**RouteLive** is a transport management system designed to organize and manage important transportation information through a centralized web application.

The system provides different interfaces for **administrators, drivers, and users**, allowing transportation data to be managed and accessed efficiently.

---

## ✨ Features

### 👨‍💼 Admin

* 🚌 Bus Management
* 👨‍✈️ Driver Management
* 🗺️ Route & Stop Management
* 👥 Member Management
* 🔧 Repair & Replacement Management
* 📊 Bus & Trip Status
* 📜 Trip History

### 👨‍✈️ Driver

* View assigned bus information
* View driver information
* Access relevant trip details
* Update transportation-related information

### 👤 User

* View available transportation information
* View bus and route details
* Access relevant trip information
* Simple and user-friendly interface

## 🚀 How to Run

### 1️⃣ Clone the repository

```bash
git clone https://github.com/kanumulah-del/ROUTELive.git
```

### 2️⃣ Open the project

```bash
cd ROUTELive
```

### 3️⃣ Install dependencies

```bash
pip install flask
```

### 4️⃣ Run the application

```bash
python app.py
```

### 5️⃣ Open in your browser

```text
http://127.0.0.1:5000
```
